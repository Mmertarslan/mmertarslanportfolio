# Premium Portföy — v3
React + Vite, tamamen Türkçe.

## Çalıştırma
Windows: `START_WINDOWS.bat` — ya da `npm install` ardından `npm run dev` (http://localhost:5173).

## Yapı
- `src/style.css`: v2'nin temel tasarımı.
- `src/premium.css`: v3 katmanı (okunabilirlik, açılış animasyonu, kart etkileşimleri). Bozarsa `main.jsx` içindeki import'u silmen yeterli.

## Sırada
Gerçek GitHub/LinkedIn linkleri (`projects.js` ve footer), gerçek proje ekran görüntüleri, CV butonu.
